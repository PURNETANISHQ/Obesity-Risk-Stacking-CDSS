# Obesity Risk Stacking CDSS

An AI-powered Clinical Decision Support System (CDSS) for high-precision obesity risk evaluation using a multi-model stacking meta-learner framework.

---

## 📌 Features

* **Multi-Model Stacking Classifier:** Integrates CatBoost, LightGBM, and Deep Learning models for multi-class risk prediction.
* **Clinical Decision Support:** Assesses risk levels based on physical, dietary, and lifestyle indicators.
* **Full-Stack Implementation:** Features a FastAPI backend and interactive frontend interface.
* **Model Evaluation Pipeline:** Includes comprehensive evaluation metrics and feature importance workflows.

---

## 🛠️ Tech Stack

* **Backend:** Python, FastAPI, Uvicorn
* **Machine Learning:** CatBoost, LightGBM, PyTorch / Scikit-Learn
* **Frontend:** JavaScript / Node.js framework
* **Data Processing:** Pandas, NumPy
